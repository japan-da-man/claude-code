# usable-ui:review: 4 つの観点で UI を点検する

**このスキルではコードを変えない。** 直すのは、ユーザーが頼んだあと。

基準は `${CLAUDE_PLUGIN_ROOT}/references/checklist.md`。最初に読む。

## 1. 対象を決める

- 引数がファイル・ディレクトリなら、その画面。
- 引数が画像なら、その画像（あればコードの場所も探す）。
- 引数が URL か、単体で開ける HTML のファイルで、Playwright が使えるなら、ライトとダーク、狭い幅（390px）と広い幅（1280px）でスクリーンショットを撮って一緒に渡す（サーバーを勝手に起動しない）。撮れないときは、見た目の指摘がコードからの推測になることを報告に書く。
- 引数がなければ、`git diff` と `git diff --staged`（なければ `git diff <base>...HEAD`）から UI のファイル（画面・部品・文言・スタイル）を選ぶ。UI の変更がなければ、そう言って終える。

画面が複数なら、画面ごとに分ける。

## 2. 前提を決める

合格基準は前提で決まる。次の順に探す:

1. `docs/product/ui-context.md` のこの画面の節
2. `docs/product/overview.md`、`docs/product/principles.md`、`actors.yaml`、仕様・要件（`docs/specs/`、`docs/requirements/`、`docs/design/`）

見つからない項目（主要ユーザー・目的・方針）は、AskUserQuestion で 1 問ずつ尋ねる。「任せる」と言われたら、画面と文書から **仮の前提** を作り、報告に仮と書く。前提なしでは点検しない。

## 3. 別の目に任せる

サブエージェント `usable-ui:ui-reviewer` に任せる。画面が複数なら、画面ごとに並べて走らせる。渡すのは次だけ:

- 対象（ファイルのパス、画像のパス、撮ったスクリーンショットのパス）
- 前提（主要ユーザー・目的・方針と、決めたトレードオフ）
- checklist のパス: `${CLAUDE_PLUGIN_ROOT}/references/checklist.md`

**作ったときの意図や会話の経緯は渡さない。** 作り手の「自分にはわかる」を持ち込まないためにコンテキストを分けている。

## 4. 結果を確かめて見せる

返ってきた指摘の `path:line` を開き、書かれたとおりのコードがあるかを確かめる。確かめられないものは「確かめきれなかったこと」に移す。

次の形で見せる。

```markdown
## 判定: 合格 / 不合格（目的を妨げる問題 N 件・必須問題 M 件）

## 前提
- 主要ユーザー / 目的 / 方針（仮なら「仮」と書く）

## 目的を妨げる問題（4 つの観点の外でも、操作しても目的が果たせない不具合）
1. `path:line` — <不具合>
   - 誰が何に困るか: …

## 必須問題（目的の達成に関わる。人が責任を持って直す）
### A. シグニファイア
1. `path:line` — <問題>
   - 誰が何に困るか: <主要ユーザーが、どの場面で、どう迷う・誤解する>
   - 案: <直し方>
### B. フィードバック
### C. UX ライティング
### D. 情報設計

## 人が決めること（トレードオフ）
- <選択肢と、どちらを選ぶと誰が何に困るか>

## 応用問題（目的に影響しない。AI に任せてよい）
- …

## 範囲外のメモ（合否に数えない）
- …

## 確かめたこと / 確かめきれなかったこと
- …
```

該当のない節は「なし」と書く。目的を妨げる問題と必須問題が 0 件なら合格（checklist の 5 節）。最後の判断（主要ユーザーが迷わず目的を達成できるか）は人がする、と 1 行添える。

## 5. 直すよう頼まれたら

- 直すのは目的を妨げる問題と必須問題。応用問題は、頼まれたものだけ。人が決めることは、決まった選択肢のとおりに直す。決まったトレードオフは `docs/product/ui-context.md` にあれば書き足す。
- 直したあとの確かめは、`usable-ui:ui-reviewer` に **直した箇所と、その修正で影響を受けた箇所だけ** を渡して見てもらう。新しい観点を足して範囲を広げない。
- 「もう一度全部レビューして」と言われたら、くり返すと別の指摘が出続けて終わらないことを伝え、大きな変更のあとの総点検としてなら行う。
